# Robot_DHTD18A2HN_2025
Robot Bluetooth ESP32 (2025) – UNETI, DHTD18A2HN. Điện thoại dùng app Bluetooth (SPP) kết nối trực tiếp ESP32, không cần tay cầm. Điều khiển 2 DC + 4 servo tay gắp; 2 chế độ: lái thường &amp; Servo-steer (X quay SV4, x thoát). Phím: F/B/L/R/S, I/G/J/H, 0–9, W/w, V/v; fail-safe 500 ms. Tác giả: Trần Đăng Khoa.
